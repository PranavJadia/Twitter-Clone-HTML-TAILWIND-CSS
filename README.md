# Twitter UI Clone 🐦

This project is a front-end clone of the Twitter (X) interface, replicating the look and feel of the official platform. Built with **HTML** and **Tailwind CSS**, it features a responsive layout with a tweet feed, sidebar navigation, profile preview, and trending topics section.

## Features

- Responsive design with Tailwind CSS
- Left sidebar with all core navigation icons (Home, Explore, Messages, etc.)
- Main tweet feed with post UI and interaction icons (like, retweet, comment)
- Tweet input box styled like Twitter's “What’s happening?” section
- Right sidebar for trending topics and suggested users to follow
- Mobile and desktop adaptive layout

## Technologies Used

- HTML5
- Tailwind CSS
- Google Material Symbols
- Responsive Web Design Principles

## How to Use

1. Clone or download this repository.
2. Make sure Tailwind CSS is properly set up (either via CDN or compiled `output.css`).
3. Open `index.html` in a browser.
4. No backend is involved; this is a static front-end project.

> **Note:** This project is for educational purposes and does not include dynamic features like real-time posting, authentication, or API integration.
